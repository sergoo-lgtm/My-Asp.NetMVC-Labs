# 🛒 MVC Product Catalog

A modern **E-Commerce Product Catalog** built using **ASP.NET Core MVC (.NET 8)** demonstrating the **Master-Detail pattern** in a clean, structured architecture.

---

## 🚀 Live Demo Route

```
/Product/ShowAll
```

---

## 🎯 Features

- 🧱 Master-Detail Implementation
- ⚡ Clean MVC Routing
- 🧠 Business Logic Layer (ProductBL)
- 📱 Fully Responsive UI (Bootstrap)
- 🧼 Separation of Concerns
- 🔁 Navigation using Tag Helpers
- 🗂️ In-Memory Data Simulation

---

## 🛠️ Tech Stack

- **C#**
- **.NET 8**
- **ASP.NET Core MVC**
- **Bootstrap 5**
- **JetBrains Rider**

---

## 📂 Project Structure

```text
📦 01-Ecommerce-Product-Catalog
 ┣ 📂 Controllers
 ┃ ┗ 📜 ProductController.cs
 ┣ 📂 Models
 ┃ ┣ 📜 Product.cs
 ┃ ┗ 📜 ProductBL.cs
 ┣ 📂 Views
 ┃ ┗ 📂 Product
 ┃   ┣ 📜 ShowAll.cshtml
 ┃   ┗ 📜 ShowDetails.cshtml
 ┗ 📜 Program.cs
```

---

## 🧠 Architecture Overview

```
User Request
     ↓
Controller
     ↓
Business Logic (ProductBL)
     ↓
Model
     ↓
View
     ↓
HTML Response
```
