# 🎓 Student Directory MVC

A modern **Student Directory** built using **ASP.NET Core MVC (.NET 8)** demonstrating the **Master-Detail pattern** in a clean, structured architecture.



---

## 🎯 Features

- 🧱 Master-Detail Implementation
- ⚡ Clean MVC Routing
- 🧠 Business Logic Layer (StudentBL)
- 📱 Fully Responsive UI (Bootstrap)
- 🧼 Separation of Concerns
- 🔁 Navigation using Tag Helpers
- 🗂️ In-Memory Data Simulation

---

## 🛠️ Tech Stack

- **C#**
- **.NET 8**
- **ASP.NET Core MVC**
- **Bootstrap 5**
- **JetBrains Rider**

---

## 📂 Project Structure

```text
📦 Student-MVC
 ┣ 📂 Controllers
 ┃ ┗ 📜 StudentController.cs
 ┣ 📂 Models
 ┃ ┣ 📜 Student.cs
 ┃ ┗ 📜 StudentBL.cs
 ┣ 📂 Views
 ┃ ┗ 📂 Student
 ┃   ┣ 📜 ShowAll.cshtml
 ┃   ┗ 📜 ShowDetails.cshtml
 ┗ 📜 Program.cs
```

---

## 🧠 Architecture Overview
```

User Request
     ↓
Controller
     ↓
Business Logic (StudentBL)
     ↓
Model
     ↓
View
     ↓
HTML Response
```
